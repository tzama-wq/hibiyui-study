# ひびゆいFC サッカーがくえん

小2(ゆいと)・小4(ひびと)向けの予習復習PWA。サッカー風ゲーミフィケーション付き。

## 動かす
```
npm start     # http://localhost:8080
npm test      # 出題ジェネレーターの検算(1万8千問)
```

## 構成
- `gen.js` … 算数の出題。答えはコードで計算。誤答選択肢に「つまずき原因タグ」付き
- `app.js` … 画面・ポイント・ランク・かくれステージ・パパにきく
- 保存先は各端末の localStorage(兄弟それぞれのスマホで別々に記録)

## 公開(GitHub Pages)
リポジトリの Settings → Pages → Branch: main / root を選ぶ。
URL をスマホで開き、「ホーム画面に追加」するとアプリとして使える。

## これから
- 国語・生活・理科・社会 … Gemini で毎朝生成(GitHub Actions)→ `data/daily/` に JSON
- 学校の単元は「パパの へや」で手動調整できる

## きょうだい共有(ランク・ゴール数を お互いに見る)
別々のスマホでも相手の記録が見えるように、無料の Firebase Realtime Database を使う。共有するのは名前・ランク・ゴール数・日数だけ。

1. https://console.firebase.google.com でプロジェクトを作る(Googleアナリティクスは不要)
2. 「Realtime Database」→「データベースを作成」(ロケーション: シンガポール `asia-southeast1` など)
3. 「ルール」タブを次に置き換えて公開
   ```json
   {
     "rules": {
       "hibiyui": {
         "$code": {
           ".read": true,
           ".write": true,
           "$kid": { ".validate": "newData.hasChildren(['xp','goals'])" }
         }
       }
     }
   }
   ```
   `hibiyui` の直下には読み取り権限がないので、**家族コードを知らない人は一覧も見られない**(コードは推測されにくい長さにする)。
4. データベースのURL(`https://〇〇-default-rtdb.〇〇.firebasedatabase.app`)をコピー
5. アプリの「パパの へや」→「きょうだいと つなぐ」にURLを入れ、「コードを つくる」→「ほぞん」→「つながりを チェック」(「つながったよ」が出ればOK)
6. 「〜用リンクを コピー」して、ひびと・ゆいと・パパ それぞれのスマホで開く(同じ設定が入る。スマホごとに1回だけ)

開発用: `node scripts/mock-db.mjs`(模擬DB、http://localhost:8787)に向ければ、Firebaseなしで動作確認できる。

## 国語(漢字)を Gemini で毎朝つくる
- `data/kanji.json` … 学年別漢字配当表(1〜4年)。`node scripts/fetch-kanji.mjs` で作成済み
- `data/kokugo-pool.json` … 出題プール。最初は手書きのシード(`node scripts/seed-kokugo.mjs`)、以降は毎朝ふえる
- `scripts/generate-kokugo.mjs` … Gemini に作らせて、**コードで検査してから**プールに追加

**AIの出力を信用しないための検査**(`scripts/lib/kokugo.mjs`)
1. 問題文・解説に、その学年で習っていない漢字があれば不採用(漢字表で機械的に判定)
2. 読みがひらがなだけか、選択肢が重複していないか等の形式チェック
3. 別の呼び出しで同じ問題を解かせ、答えが一致しなければ不採用(二重検算)

**Gemini APIキーの設定**(あなたの操作が必要)
1. https://aistudio.google.com/apikey でキーを作る(無料)
2. GitHub のリポジトリ → Settings → Secrets and variables → Actions → New repository secret
   名前 `GEMINI_API_KEY`、値にキーを貼る(**チャットやコードには書かない**)
3. Actions タブ → daily-kokugo → Run workflow で試す。結果は `data/last-run.json` に残る
- モデルは自動で選ばれる(固定したいときは Secret ではなく環境変数 `GEMINI_MODEL`)
- 無料枠では、送った内容が Google のモデル改善に使われうる。**送るのは漢字の一覧と問題文だけ**で、子どもの情報は送らない
- 手元で試す: `GEMINI_API_KEY=... node scripts/generate-kokugo.mjs --grades 2 --count 4`

## スマホごとの持ち主(ひびと/ゆいと)
- 最初の1回だけ「このスマホは だれの?」を選ぶ(その時に**パパのPIN**を決める)。以後は、その子の画面しか開かない。**相手の問題は開けない**(きょうだいの記録は見るだけ)。
- 持ち主の変更・「パパの へや」(右上の ⚙)には PIN が要る。PIN を忘れたら、ブラウザのサイトデータを消す(記録も消える)。
- 設定を楽にするリンク: 「パパの へや」→「きょうだいと つなぐ」で、子ども別のリンク(`#kid=hibito&db=…&fc=…`)をコピーできる。リンクを開くだけで、そのスマホの持ち主と共有設定が入る(持ち主が未設定のときだけ)。

## 理科・社会・生活(事実リスト方式)
- `data/know/*.json` に人が確かめた4択問題を置き、`node scripts/build-knowledge.mjs` で検査して `data/knowledge.json` にまとめる(アプリはこれを読む)
- 検査: 学年外の漢字は `{漢字|よみ}` のルビにしていないとエラー / 選択肢の重複 / 誤答ごとの「なぜ違うか(note)」が必須 / 1単元12問以上
- 偏りの検査: `node scripts/lint-knowledge.mjs`(正解が最長・最短の問題が多すぎないか)
- 追加の流れ: ファイルに問題を足す → `node scripts/build-knowledge.mjs` → `npm test` → コミット

## PIN(パパ用・子ども用)
- **PINの値は、コードにもGitHubにも書かない**(このリポジトリは公開のため)。各スマホの中にだけ、暗号のような形で保存される。
- **パパのPIN**: 「パパの へや」・持ち主の変更・PINの管理に必要。子ども用リンクで開いたスマホは、最初にパパがPINを決めるまで何も開けない。
- **子どものPIN**(任意): パパの へや →「🔐 PIN」で、ひびと/ゆいと別に設定。設定すると、その子の画面を開くたびにPINを聞かれる(右上の 🔒 でもロックできる)。
- **2人で1台を使うモード**: 「パパの へや」でオンにすると、最初に「だれが つかう?」を選び、本人のPINで開く。
- PINは**スマホごと**に設定する(3台なら3回)。忘れたら、ブラウザのサイトデータを消す(そのスマホの記録も消える)。

## ガチャ・選手・チーム・対戦(`game.js` = ルール、`ui-game.js` = 画面)
**チケットの もらいかた**(お金は一切つかわない)
- 勉強: 1セットで6割以上せいかい → ブロンズ1枚 / パーフェクト → シルバー1枚 / かくれステージ・タイムマシンはさらに+1枚。1日の上限は6枚
- ログインボーナス: 「連続」ではなく**通算の日数**(休んでも減らない)。3日目シルバー1、7日目シルバー2、14日目ゴールド1、30日目プラチナ1+ゴールド1(以後も7・14・30の倍数日)
- 最初に ブロンズ3 + シルバー1

**ガチャの確率**(ブロンズの場合): コモン60 / アンコモン28 / レア9.5 / スーパーレア2.48 / レジェンド0.02(%)。上位チケットほど低いレアが出ない(ブロンズ=なし、シルバー=アンコモン以上、ゴールド=レア以上、プラチナ=スーパーレア以上)。レジェンドは**チケットがいいほど出やすい**(ブロンズ0.02% / シルバー0.1% / ゴールド0.5% / プラチナ2%。最大2%)。選手は220人(コモン80・アンコモン60・レア44・スーパーレア24・レジェンド12)。**レア・スーパーレア・レジェンドの80人は、有名な選手を「モデル」にしたオリジナルのキャラクター**(名前はもじり。本人とは関係ない。国旗とタイプ=得意な動きつき。日本人モデルは21人)。コモン・アンコモンの140人は完全オリジナル。選手を足すときは**配列のうしろに足す**(選手IDと能力が変わらないよう、選手ごとに乱数を固定している。テストで固定値を確認)。実在の本名・クラブ名・写真は使わない。同じ選手がダブるとレベルアップ(最大Lv5、1つで能力+4%)。
**確率を変えたいとき**: `game.js` の `BASE_RATES` と `LEGEND_RATES`(テストが確率を検算する)

**強化**: 算数→シュート / 国語→パス / 理科→スピード / 社会→まもり / 生活→スタミナ。せいかい1つで+2pt。Lvが上がるほど必要ptが増える(1〜10Lvは1pt、11〜20Lvは2pt…)。強化値は `30 + Lv×1.5` で、**Lv47でレジェンドの最大(99)をこえる**。Lv100が上限。
**メダルのバフ**: メダルごとにチーム全体が% 強くなる。3つまで装備。上限+40%。
**対戦**: 11人(4-4-2: FW2・MF4・DF4・GK1)で、CPU(4段階)か、きょうだいのチーム(同じスマホか共有設定ずみのとき)と戦う。結果は運も入る(強いほうが勝ちやすい)。勝敗の景品はない(チケットは勉強とログインだけ)。

## 選手のイラスト(レア以上の80人)
- `images/players/*.webp`(320px・各約25KB)。Higgsfield(`gpt_image_2_5`)で作った、**タイプ・ポジション・レア度に合わせたデフォルメのオリジナルキャラ**。実在の人物の顔には似せていない(名前・顔・チームを指定せず、モチーフ=動物や道具だけで描き分け)。
- 画像が読み込めないときは、これまでの絵文字の顔に自動で戻る。コモン・アンコモンは絵文字のまま。
- 画像は `game.js` の `img` で指す。足すときは同じ名前(選手ID.webp)で `images/players/` に置く。
- ※ このリポジトリは公開設定。画像を公開したくないときは、リポジトリを非公開にするか、画像をコミットしない運用にする。

## 国語の自動生成の ふんばり(混雑・採用率)
- **混雑(HTTP 503/429)**: 待ち時間を 8秒→25秒→60秒と のばして 3回ためし、だめなら **次の モデル**(利用できる flash 系を 新しい順)に きりかえる。学年の あいだは 15秒あけ、失敗した学年は 90秒後に もう1回。
- **採用率**: プロンプトで「sentence には target を 漢字のまま ちょうど1回」「wrong の漢字も 一覧の中だけ」と明記。AIが ひらがなのまま書いた文は、安全に 漢字へ おきかえる(あいまいなら 直さずに 不採用)。**落ちた漢字だけ**を、落ちた理由つきで もう1回 たのむ。
- **原因が見える**: `data/last-run.json` に、落ちた問題の じっぶつ(`samples`)と 理由、何回戦まで やったか(`rounds`)、取れなかった数(`missing`)が のこる。
- **1日2回**(日本時間 5:00 と 17:00)。午前と午後で ちがう漢字を選ぶ(`--part 0/1`)。

## やさしい せってい(ADHD・ASD などの おこさんへの はいりょ)
**診断や治療ではありません。** 学習アプリで よく使われる「はいりょ」を、**子どもごとに選べる設定**にしたものです(パパの へや →「🧩 やさしい せってい」)。どれが合うかは子どもによって違うので、1つずつ試して合うものを残してください。学校・かかりつけ・支援機関のアドバイスがあれば、そちらを優先してください。

| 設定 | 何が かわるか |
|---|---|
| 1セットの もんだい数(3/5) | 集中が続きにくい子向けに短く区切る |
| 🐢 うごき・ひかりを へらす | 紙ふぶき・ゆれ・光・カードのかたむき・ガチャのカプセル演出をなくす(スマホの「動きを減らす」にも従う) |
| 🔇 おと・ふるえを けす | 音とバイブを止める(上バーの 🔊 からも変えられる) |
| 💬 たとえを つかわない | 「キーパーに とめられた」などの比喩をやめて、「ちがうよ。だいじょうぶ」などそのままの言葉に |
| 📋 はじめる まえに やることを みせる | 始める前に、順番・問題数・だいたいの時間・終わり方を見せる。順番はいつも同じ(シャッフルしない) |
| 🌱 できなかったを みせない | 日本代表の「ひかえ」、週の空の丸、きょうだいカードの「ひかえ」を隠す |
| 🗓️ きょうの やること | ホームに、今日のやることリスト(終わりが分かる) |
| 🍃 きゅうけい | 1セットごとに1分の休憩画面(ゆっくり広がる丸。強制ではない) |
| 🔠 おおきい もじ | 文字を大きく |
| 「よく よんでね」の まち | ふつう(1.5〜3.5秒) / みじかい / なし |
| まちがえた あとの まち | ふつう(4秒) / みじかい / なし |
| ガチャ 1日の かいすう | 0=制限なし / 1・3・5・10回まで(「いつ当たるか分からない」報酬は、衝動性が強い子には ひきすぎの原因になりうる) |

**おすすめセット**(あとから1つずつ変えられる): ADHD向け=3問・休憩・短い待ち・今日のやること・ガチャ5回まで / ASD向け=動きと音を減らす・たとえなし・見通し・できなかったを隠す・ガチャ3回まで。

**全員に入った変更**(設定に関係なく)
- まちがえても **「ちょうせんポイント +2」** が必ず付く(ゼロにしない)
- 「やすむ」でも、そこまでのポイントは **とっておく**(いままでは消えていた)
- 結果の星は、最後までやったら **1つ以上**
- 問題中に「あと◯もん」を表示

## しあい えいぞう(ピクセル)
- 「チーム」→「たいせん」の しあいは、11人ずつの ドットの 選手が プレーする 映像で 見られる(`match.js`)。パス → シュート → ゴール/セーブ/はずれ、ゴールの おいわい、ハーフタイム、カメラが ボールを おいかける。
- ⏩ はやおくり / ⏭ とばす。しあいの あとは「✨ ダイジェスト(ゴールだけ)」「🎬 ぜんぶ みる」で もう一度 見られる。メニューからも 前の しあいを 見られる。
- フォーメーションを かえると、映像の 選手の ならびも かわる。「やさしい せってい」の「うごきを へらす」では 映像を 出さず、ぶんしょうだけで しあいを すすめる。

## たいかい(Jリーグ → アジアカップ → KIRINカップ → ワールドカップ)
- 「チーム」→「たいかい」。じゅんばんに かって つぎの ラウンドへ。まけると はいたい(1かいせんから)。ゆうしょうすると つぎの たいかいが ひらき、メダル(チームバフ)と チケットが もらえる。
- ひきわけは PK戦で けっちゃく。てきの つよさは「じぶんに あわせず」きまっている(34〜105)。こうげき/まもり/バランスの タイプが あり、「かてそう ★」が めやすで 出る。はじめの チームは ボス(レジェンド)には かてない。
- 「やさしい せってい」の「まけても おなじ しあいから やりなおせる」(ADHD・ASD の プリセットで オン)で はいたいを なくせる。
- フリーマッチ(CPU・きょうだい)も、CPU は きまった つよさ(30〜110)。

## こっき あてクイズ

## パパも さんか
- パパは 3人めの 選手(`#kid=papa` の リンク、または「このスマホは だれの?」で「パパ」)。小4の もんだいに ちょうせんして、ガチャ・チーム・たいかい・たいせんが できる。ひびと・ゆいとと「かぞく たいせん」も できる(きょうだいと つないでいる とき)。
- パパだけの PINは 「パパの へや」→「子どもの PIN」で きめられる。日本代表の ボーナスは 子ども ふたりぶんだけで、パパは かんけいない。
- 「パパの へや」の PIN(パパの へや を ひらく もの)とは べつの ものです。

- 「すきな れんしゅう」でも 6わり いじょう せいかいで チケットが もらえる(1日4まい。きょうの セットの 上限(6まい)とは べつわく)。

## 境界知能・ASD むけの せってい(「パパの へや」→「やさしい せってい」)
- プリセット: **ゆっくり じっくり(境界知能)**/ ASD / ADHD / ぜんぶ ふつうに もどす。どれも あとから 1つずつ かえられる(診断や治療ではなく「よくある はいりょ」)。
- 境界知能むけ: 1セット3もん・ことばを やさしく(たとえなし)・「できなかった」を みせない・はじめに やることを みせる・まつ じかんは ふつう(よむ じかんを みじかくしない)・**せんたくしを 3つに へらす**・**💡ヒント(まちがいを 1つずつ けす)**・**もんだいの じどう よみあげ**・たいかいで まけても やりなおせる。
- ASD むけ: うごき・おと・ひかりを へらす・たとえなし・「やること」を さきに みせる(じゅんばんも おなじ)・やりなおせる。
- 新しい 項目: `せんたくしの かず(ぜんぶ/3つ/2つ)`・`ヒント`・`じどう よみあげ`・`1セット 2もん`。かたちを たしかめる もんだい(つまずきの かせつ)では「わな」の せんたくしは のこす。

## 九九マスター / といの ばらつき / PK戦
- 「れんしゅう」タブの「九九マスター」: 1〜9の だん ごとの れんしゅう、九九 ぜんぶ、□を さがせ。9だん ぜんぶ「できた」で メダル。かたち(a×b / b×a / a×□=c)が まざる。
- かたち・はた クイズは 1つの 県・国に つき 5しゅるいの とい(かたち→なまえ / なまえ→かたち(えらびかたが 絵)/ 県庁所在地・しゅと / 地方・たいりく / しゅと→なまえ)。小2は 2しゅるい。
- しあいが どうてんなら すべて PK戦(フリー・きょうだい・たいかい)。ゴール/セーブ/はずれを 映像で みせる。

## ランク(25だん)
- サッカーきょうしつ → ジュニアユース → … → Jリーガー(2500) → にほんだいひょう(7600) → ヨーロッパの スター(18500) → ワールドカップの スター(30000) → バロンドール(41000) → **サッカーの でんせつ(50000)**。
- ポイント(xp)の きろくは そのまま。ランクの なまえが ふえた ぶん、いまの ランクが かわって 見える ことが ある。うけとった メダルは のこる。

## かぞくの チーム・パパへの しつもん・プレゼント・つよく(ガチャ選手)
- 「チーム」→「かぞく」で、かぞくの へんせい(フォーメーション・パワー)を みられる(みるだけ)。
- 「パパに きく」は、つながっていれば パパの スマホに とどく(⚙ に 赤い 数字)。パパが「おしえたよ」を おすと、ほんにんの スマホからも きえる。つながっていない ときは LINEなどに おくる(「パパの へや」で つなぐ せっていが いる)。アプリを ひらいた ときと 45びょうごとに じどうで かぞくの きろくを うけとる。
- パパの へやの プルダウンが ひらいた とたんに とじる 不具合を なおした。
- ガチャで ゲットした 選手も ポイントで「きょうか」できる(ずかん → 選手 → きょうか。1かい +3%・さいだい 20かい。レア度が たかいほど ポイントが いる。のうりょくは さいだい 140)。
- プレゼント: `data/gifts.json` に かくと、ひとりに 1かいだけ アプリを ひらいた ときに うけとれる(チケットなど)。
- 国・国旗クイズは 197か国(国の かたちは Natural Earth 50m、旗は flag-icons)。`node scripts/build-geo.mjs <japan.geojson> <ne_50m_admin_0_countries.geojson>` / `node scripts/build-flags.mjs <svgフォルダ>`。
